# Mini Department Prediction Model

This mini project is a Machine Learning-based system that automatically predicts the appropriate department for a given complaint. It uses Natural Language Processing (NLP) techniques with CountVectorizer and a Multinomial Naive Bayes classifier to classify complaint text into predefined departments.

🚀 Features
Automatically classifies complaints into departments
Uses NLP for text preprocessing and feature extraction
Lightweight and fast model using Multinomial Naive Bayes
Easy to train and extend with new data.
Suitable for customer support systems and complaint management platforms.

🛠️ Tech Stack
Python
Scikit-learn
Pandas
